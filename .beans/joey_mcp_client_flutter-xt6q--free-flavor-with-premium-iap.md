Build a separate free-with-IAP variant (Joey Free) via Flutter flavors. Free tier: single persisted conversation, single MCP server, no on-device tools. Premium (one-time non-consumable IAP com.kaiserapps.joey.free.premium) unlocks unlimited history, unlimited MCP servers, and all on-device tools. Open-source builds and the pro flavor are fully unlocked via a compile-time JOEY_FREEMIUM flag (default false). iOS + Android, including store-side setup.
